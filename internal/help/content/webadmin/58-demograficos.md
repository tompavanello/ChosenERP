# Demograficos

O painel **Demograficos** mostra o perfil da igreja.

## Usar

1. Abra **Relatorios > Demograficos**.
2. Analise idade, situacao, estado civil e distribuicao por cidade/UF.
3. Exporte para planejamento.

## Escopo

- Respeita a filial ativa.
- Depende dos dados preenchidos no cadastro; campos vazios reduzem a precisao.

## Boas praticas

- Use para planejar ministerios e eventos.
- Incentive o preenchimento de cidade/UF e data de nascimento.
- Compare periodos para ver tendencias.
