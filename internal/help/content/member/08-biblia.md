# Biblia

## Ler

1. Abra **Biblia**.
2. Escolha a versao disponivel.
3. Navegue por livro e capitulo.

A igreja define a versao padrao. O texto vem de uma API licenciada (`api.bible`) com cache local.

## Se o leitor estiver indisponivel

A igreja pode nao ter configurado a chave da API. Fale com a secretaria ou use a busca do manual.

## Boas praticas

- Use a mesma versao nos estudos para facilitar a conversa.
- Anote as referencias no seu devocional.
- O app precisa de internet para carregar novos capitulos (os ja lidos podem ficar em cache).
