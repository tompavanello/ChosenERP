# Meu perfil, familia e frequencia

## Dados pessoais

- Nome, situacao, datas de nascimento/batismo e carteirinha.
- Para corrigir dados cadastrais, use **Solicitacoes** ou procure a secretaria.

## Contato

Toque em **Editar** para atualizar e-mail, telefone e WhatsApp. Esses dados sao usados pela igreja e pelo login.

## Familia

Veja as familias das quais voce participa.

## Push

Ative/desative as notificacoes do dispositivo. Se nao receber, verifique as permissoes do navegador.

## Frequencia

Abra **Minha frequencia** para ver seu historico de presencas.

## Senha

Se a senha foi definida como provisoria, o app pede a troca no primeiro acesso. Use uma senha forte.

## Ajuda

Use o **?** no topo para o guia desta tela, IA ou chamado de suporte.
