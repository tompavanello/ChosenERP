E tem uma coisa importante: como você já está pensando em um sistema para o Rol de Membros, eu faria o aplicativo já nascer com um banco de dados central da igreja. Assim o cadastro feito pelo membro alimenta o Rol, o GD usa o mesmo cadastro, a secretaria usa o mesmo cadastro e futuramente a tesouraria também.
Isso evita ter um sistema para o membro + outro para o secretário + outro para o GD.
